## 📜 COMMON JAVASCRIPT FUNCTIONALITY

### API Integration
- Fetch `/api/status` to determine login state and show correct auth button.
- Fetch `/api/admin/check` to conditionally show admin button.
- Fetch `/api/plan-prices` on homepage to update displayed credit costs.
- Razorpay integration (when enabled): `/api/create-order` and `/api/verify-payment`.

### Form Handling
- All forms use `fetch` with proper loading states.
- Manual code verification:
  - When user selects “No”, immediately call `/api/request_scan` with `emailOnSite='no'`. On success, display the code panel and populate the code.
  - “Verify Code” button sends the verification token to `/api/verify_code` and on success redirects to profile (or shows a modal with bullet points and a “Got it” button).
- Email verification:
  - When user selects “Yes”, a “Verify Now” button appears. Clicking sends the form to `/api/request_scan`. Success message appears, form section hides.

### Message Display
- Use a unified `showMessage(message, isError)` function that uses either the toast or a modal (based on message content). For success messages like “Verification successful!”, a modal with a “Got it” button is used; for simple toasts, the bottom‑right box.

### Responsive Behaviour
- On mobile (<768px):
  - Navbar stacks vertically.
  - Cards become full‑width.
  - Forms stack inputs.
  - Dashboard grid becomes single column.
